# Security Policy

## Supported Versions

The most recent minor version receives fixes. Older versions are updated only if a backport is requested and is reasonable.

## Reporting a Vulnerability

Please report a vulnerability by opening a [security advisory](https://github.com/JAXtronomy/spexial/security/advisories/new), or by opening an issue if the problem is not sensitive. Fixed vulnerabilities result in a bugfix, minor, or major release depending on what the fix requires.
