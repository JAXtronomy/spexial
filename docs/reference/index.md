# Reference

Descriptions of what `spexial` provides: signatures, supported domains, measured accuracy, and the rules the API follows. Consult these while working; they are not written to be read through.

- [API reference](api.md) — every public function, generated from the source.
- [Accuracy and domains](accuracy-and-domains.md) — the supported input range and measured error of each function. **The canonical home for these facts**; the rest of the docs link here.
- [Conventions](conventions.md) — naming, argument order, and what is public.
- [Errors](errors.md) — what raises, what returns `nan` instead, and why the distinction is not arbitrary.

If you want to know _why_ a limit is where it is, that argument lives in [Explanation](../explanation/index.md).
