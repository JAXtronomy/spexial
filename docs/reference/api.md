# API reference

Everything below is exported from the top-level `spexial` namespace:

```python
import spexial as sp
```

Names match `scipy.special` wherever a counterpart exists; see [Conventions](conventions.md) for the rules, and [Accuracy and domains](accuracy-and-domains.md) for the supported input range of each function.
